# Support

## Before Asking for Help

Please check existing:

- Documentation in [`docs/`](docs/)
- Open and closed issues
- `README.md` project status and constraints

## Asking Questions

Use GitHub Issues for project questions and clearly label context, goal, and what you already tried.

## Reporting Bugs

Use the Bug Report issue template and include:

- Environment details
- Exact reproduction steps
- Expected vs actual behavior
- Relevant logs/output

## Security Issues

Do not report security vulnerabilities in public issues.

Follow [`SECURITY.md`](SECURITY.md).

## Scope Reminder

OMERTA is currently in a foundation phase. Some feature requests may be deferred until core architecture is implemented.
