# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please use **GitHub Private Vulnerability Reporting** for this repository when available.

- Preferred path: repository **Security** tab -> **Report a vulnerability**
- Do **not** open a public issue for security vulnerabilities

If private reporting is not enabled yet, open a minimal issue requesting a secure contact path without disclosing exploit details.

## What to Include

Provide as much of the following as possible:

- A clear vulnerability description
- Affected components and paths
- Reproduction steps or proof of concept
- Impact assessment
- Suggested remediation (if known)

## Response Expectations

The project is in an early stage; response SLAs are not guaranteed yet. Maintainers will triage reports as quickly as practical.
