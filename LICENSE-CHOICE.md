# License Selection Required

OMERTA does not yet include a finalized open-source license.

Before distribution, reuse, or external contribution at scale, the maintainer must select and commit an explicit license file (for example `LICENSE`) that reflects intended usage rights and obligations.

## Why this file exists

A public repository without a license is generally treated as "all rights reserved" by default. This placeholder prevents ambiguity and signals that licensing is intentionally pending maintainer decision.

## Maintainer action needed

1. Choose an appropriate open-source license.
2. Add the full license text in a `LICENSE` file at the repository root.
3. Update `README.md` and this file to reflect the selected license.
